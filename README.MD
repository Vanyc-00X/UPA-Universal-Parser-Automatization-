# UPA — Universal Parser Automatization

Локальное приложение: изучает сайт, строит карту элементов, сохраняет сценарии
сбора или ввода данных и запускает их с отчётом о полноте / ошибках по строкам.

Работает на вашем ПК. Веб-интерфейс в браузере. ИИ (Ollama) усиливает анализ,
но **не обязателен** — без модели доступны эвристики и ручной выбор.

## Быстрый старт

```powershell
.\run.ps1
# или двойной клик:
.\launch.cmd
```

Ярлык на рабочий стол:

```powershell
.\scripts\create-shortcut.ps1
```

Подробнее: [docs/quickstart.md](docs/quickstart.md)

## Возможности (этапы 0–8)

1. Съёмка страницы (Playwright): DOM, скриншоты, сеть, storage state  
2. Карта элементов и отчёт о странице  
3. Визуальный редактор и версии сценариев  
4. Движок извлечения, пагинация, отчёт о полноте  
5. Экспорт CSV/XLSX/JSON и Markdown-ТЗ  
6. Self-healing селекторов (предложение без автоприменения)  
7. Воркфлоу ввода: dry-run, CSV/XLSX, запись, экспорт Playwright-скрипта  
8. Онбординг, шаблоны, лаунчер, документация
