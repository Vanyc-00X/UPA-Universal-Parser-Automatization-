UPA (Universal Parser Automatization) - Приложение, которое изучает нужный сайт,  собирает с него весь контекнт и показывает, и может Автоматизировать сбор данных или ввод данных или последущие. 


Приложенние,запускаеться на пк локально. Открываеться веб интерфейс в браузере. Можно вставить url сайта. ИИ скопирует, проанализирует и расспишет какие элемент есть и за что они отвечают. Пользователь может заменить значение  элемента( напимер дать определонному input значение "наименование товара). Позже, можнозапросить парсинг данных, автоматизации. Пользователь дделает сценраии. А ИИ, либо парсит либо делает ТЗ для ИИ в MD формате.
Должен быть Парсинг, Анализ сайта и автоматизацияя исходя из сценария пользователя.
