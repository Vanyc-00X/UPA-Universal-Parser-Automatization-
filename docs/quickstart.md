# Быстрый старт UPA

## Требования

- Windows 10/11
- Python 3.10+
- Node.js 18+ (для веб-интерфейса)
- Опционально: [Ollama](https://ollama.com) и модель `qwen2.5:7b`

## Запуск

Из корня репозитория:

```powershell
.\run.ps1
```

Или ярлык / `launch.cmd` — тот же лаунчер.

Откроются:

| Сервис | Адрес |
|---|---|
| Веб-интерфейс | http://127.0.0.1:5173 |
| API | http://127.0.0.1:8000 |
| OpenAPI | http://127.0.0.1:8000/docs |

## Первый сценарий за 5 минут

1. **Сайты** → вставьте URL каталога → «Снять снапшот».
2. **Карта элементов** → проверьте поля → сохраните сценарий.
3. **Сценарии** → «Запустить» → смотрите записи в **Запусках**.
4. При падении заполненности откройте предложение self-healing (патч не применяется сам).
5. Для ввода данных: **Воркфлоу** → CSV → Dry-run → Live с подтверждением.

## Без ИИ

Если Ollama не запущена, UPA работает на эвристиках и ручном выборе элементов.
На дашборде будет статус «ИИ недоступна» — это штатно.

Чтобы подтянуть модель из интерфейса: Обзор → «Загрузить модель», либо:

```powershell
ollama pull qwen2.5:7b
```

## Docker

```powershell
docker compose up --build
```

API: http://127.0.0.1:8000 (фронтенд в образе отдаётся статикой, если собран).
