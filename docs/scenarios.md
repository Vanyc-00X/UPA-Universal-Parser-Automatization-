# Руководство по сценариям

## Два типа сценариев

| kind | Назначение | Где править |
|---|---|---|
| `collection` | Сбор данных (парсинг) | Карта элементов → Сценарии |
| `form_fill` | Ввод данных (воркфлоу) | Воркфлоу |

## Сценарий сбора

1. Снимите снапшот страницы.
2. В карте элементов отметьте поля (title, price, …).
3. Выберите режим: `list` (карточки) или `single` (одна запись).
4. Настройте пагинацию: `none`, `next_link`, `url_template`.
5. Сохраните сценарий — появится версия v1, v2, …
6. Запуск пишет записи в БД и отчёт о полноте.

**Self-healing:** если заполненность упала, UPA предложит патч селекторов.
Применение только по явной кнопке — без «тихого» изменения.

## Воркфлоу ввода

1. Соберите шаги: `goto`, `fill`, `click`, …
2. Параметры — CSV или XLSX; в значениях используйте `{{column}}`.
3. **Dry-run** проверяет селекторы на DOM снапшота без отправки формы.
4. **Live** идёт через Playwright; опасные click требуют `confirm_dangerous`.
5. **Экспорт .py** — самостоятельный скрипт без UPA.

### Запись действий

Вставьте JSON событий (как у Playwright codegen) → «Применить запись».
UPA укоротит селекторы, предложит `{{column}}` и пометит submit.

### Управляющие шаги

- `if` — условие: `exists:#sel`, `missing:#sel`, `text:…`, `column:name`, `equals:key=value`
- `loop` — `loop_times` или колонка со списком через запятую (`loop_over`)
- `upload_file` — путь к файлу или `{{file}}`

## Шаблоны

В разделе **Шаблоны** или API `GET /api/v1/templates` лежат заготовки
«Каталог», «Форма заявки», «Статья» с примером CSV.
