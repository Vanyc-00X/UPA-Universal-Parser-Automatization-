# Политика ретенции данных

UPA работает **локально** на вашем ПК. Данные не отправляются в облако UPA
(облачный LLM — только если вы сами включили fallback в настройках).

## Что хранится

| Данные | Где | Заметка |
|---|---|---|
| SQLite БД | `data/` (или путь из настроек) | сайты, снапшоты, сценарии, запуски |
| HTML/DOM/скриншоты | `data/artifacts/` | артефакты съёмки и экспорта |
| Chromium Playwright | `data/_pw-browsers/` | кэш браузера |
| Логи | stdout / настройка логирования | без паролей по умолчанию |

## Рекомендации

- Периодически удаляйте старые снапшоты и запуски из интерфейса.
- Не коммитьте каталог `data/` в git (он в `.gitignore`).
- Перед передачей ПК другому человеку очистите `data/` — там могут быть
  cookies и содержимое страниц из storage state.
- Экспорты CSV/XLSX содержат собранные персональные/коммерческие данные —
  храните их по своим правилам организации.

## Удаление

Удаление снапшота/сценария/запуска через API или UI удаляет связанные записи
в БД и (где применимо) файлы артефактов. Полный сброс: остановите UPA и
удалите каталог данных.
