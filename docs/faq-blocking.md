# FAQ: блокировки и антибот

## Сайт отдаёт пустую страницу / 403

- Попробуйте headed-режим: `.\run.ps1 -Headed`
- Проверьте, не режет ли сайт дата-центр IP (локальный ПК обычно лучше).
- Снимите снапшот после ручного логина (storage state сохраняется в артефактах).

## Cookie-баннер мешает

UPA пытается закрыть типичные баннеры при съёмке. Если не вышло —
зафиксируйте селектор кнопки «Принять» в воркфлоу (`click`) перед сбором.

## robots.txt

Эндпоинт `GET /api/v1/robots/check?url=…` показывает, разрешён ли путь.
Соблюдение ToS и robots — ответственность пользователя (см. дисклеймер).

## Селекторы «сломались»

1. Откройте запуск → предложение self-healing.
2. Проверьте карту элементов на свежем снапшоте.
3. Добавьте `fallback_selectors` у полей.
4. Не полагайтесь только на длинные CSS-пути — лучше `#id` и устойчивые классы.

## Капча / Cloudflare

Автоматический обход капчи не входит в UPA. Используйте ручной вход в headed-
режиме и сохранённую сессию, либо другой источник данных (API/XHR сайта).
