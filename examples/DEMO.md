# Демо: от URL до таблицы за 5 минут

Ниже — минимальный сценарий «как это ощущается», без настройки облака и без обязательного ИИ.

## 0. Запуск

```powershell
.\run.ps1
```

Откройте http://127.0.0.1:5173

## 1. Сбор данных с каталога

1. **Сайты** → вставьте URL каталога → **Снять снапшот**.
2. **Карта элементов** → проверьте поля `title`, `price`, `url`.
3. Сохраните сценарий (или возьмите шаблон «Каталог товаров»).
4. **Сценарии** → **Запустить**.
5. **Запуски** → смотрите записи и полноту; экспорт в CSV/XLSX.

Пример определения сценария: [`catalog-scenario.json`](catalog-scenario.json)

```json
{
  "plan": { "mode": "list", "item_selector": ".product-card" },
  "fields": [
    { "key": "title", "selector": ".product-card__title", "required": true },
    { "key": "price", "selector": ".product-card__price" }
  ]
}
```

## 2. Ввод данных из CSV (обратный режим)

1. **Воркфлоу** → шаги `fill` / `select` с `{{name}}`, `{{email}}`.
2. Вставьте CSV из [`params-form.csv`](params-form.csv).
3. **Dry-run** на снапшоте формы — без реальной отправки.
4. **Live** только после галочки подтверждения опасных действий.

Пример воркфлоу: [`form-workflow.json`](form-workflow.json)

```csv
name,email,city
Иван,ivan@example.com,msk
Мария,maria@example.com,spb
```

## 3. Когда вёрстка сайта изменилась

1. Откройте упавший запуск.
2. Посмотрите предложение self-healing.
3. Примените патч **явно** — UPA никогда не меняет сценарий молча.

## 4. Экспорт «без UPA»

На странице воркфлоу: **Экспорт .py** → получите самостоятельный Playwright-скрипт.
